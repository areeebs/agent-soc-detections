# Security Policy

Report security issues privately to the repository maintainer rather than opening a public issue with exploit details. Include the affected commit, a minimal reproduction, and the impact. Do not include real prompts, credentials, customer data, or production traces in reports or fixtures.

This tool analyzes local metadata and does not execute agent tools. Its output is not an authorization decision or a substitute for runtime controls. Treat imported telemetry and generated findings as potentially sensitive incident data.
